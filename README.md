# Sales demo — Subtext

## Основные файлы
- `index.html` — страница входа.
- `lk.html` — личный кабинет ученика.
- `subtext.js` — логика личного кабинета и загрузки материалов.
- `config.js` — настройки бренда и адреса API.
- `apps-script.js` — исходный код Google Apps Script (серверная часть).

## Раздел «Материалы»
Материалы загружаются из листа «Материалы» в таблице курса через Google Apps Script. Для отображения в кабинете в ответе API должен приходить массив `materials` с полями `title`, `link` и `course`. В таблице должны быть заполнены название и ссылка на материал.

В кабинете доступны поиск по названию и фильтры по значению столбца сортировки (если он заполнен).

## Публикация
Страницы входа и кабинета должны лежать рядом с `config.js` и `subtext.js` на одном хостинге. Google Apps Script публикуется отдельно как веб-приложение; его URL указывается в `config.js`.
